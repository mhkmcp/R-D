How these are computed

Each test picture is run twice: once through the original model (negative, should not be flagged) and once through the current, corrupted model (positive, should be flagged). TP = corrupted and flagged, FN = corrupted and missed, FP = original and flagged, TN = original and not flagged. Recall = TP / (TP+FN), precision = TP / (TP+FP), F1 = their harmonic mean, false-alarm rate = FP / (FP+TN). Precision and F1 depend on the 50 / 50 mix used here; recall and false-alarm rate do not. A fault that leaves an answer unchanged is not harmless in itself, but it cannot be seen from the answer, so it is reported separately and never mixed with changed answers.
